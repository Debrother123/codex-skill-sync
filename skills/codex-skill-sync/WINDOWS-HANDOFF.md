# 新电脑 / 新智能体接管入口

请先阅读本目录 SKILL.md，再执行对应环境的首次接入 SOP。不限于 Windows 或 Codex，也可用于 Mac 上的 WorkBuddy 等智能体。

源仓库： https://github.com/Debrother123/codex-skill-sync
管理工具路径： skills/codex-skill-sync

由当前智能体自行确认自己的 skills 目录、核验格式和依赖、修改必要的平台适配，并验证，不把这些步骤转交用户。按用户授权范围完成例行适配。缺少快捷方式位置时问用户该位置，不把 Mac 路径猜成 Windows 路径。

使用 scripts/bootstrap.py init 登记独立环境，安装工具并生成用户指定位置的快捷方式。相同参数重复运行可复用；已有同名差异先比较并备份。连接 GitHub 需要本机已有安全登录，不复制另一台电脑凭据。

支持离线初始化。先读取远程实际内容，不能只凭说明宣称已下载或已验证。首次仅同步明确选中的 skills，兼容性差异由当前智能体处理，共享修正和专用版本分别存放。

最终报告本机环境、安装目录、快捷方式、适配结果、连接状态、实际同步内容、SHA 及未完成事项。
